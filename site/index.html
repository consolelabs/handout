A Console Labs product

Hand out a link that looks like yours.

Hand out a file, a folder, a guide, a deck, a build or a dev server at a link on your own domain. The link expires when you say so, counts who opened it, can be private, and a folder gets a page of its own. Like ngrok, but the hostname is yours and stays the same.

For people who send things to other people

Handout is for anyone who wants the link to look like theirs. Pick what you hand out and who gets it.

A client or a teammate

A file

https://s.example.com/<id>/report.pdf, public or private to named emails, gone after 7 days.

A team or a class

A folder, a guide, a deck

One link with a generated page: videos play inline, images show as a grid, files list with type and size.

Testers

A build or a prototype

A snapshot link that survives deleting the source, refreshed under the same link.

A reviewer

A running dev server

handout add 3000 proxies 127.0.0.1:3000 while it runs. The hostname does not change at every start.

Everyone you work with

Anything, from a whole team

One hostname, one shared list, each teammate publishing from their own machine.

A coding agent

Whatever it just built

handout skill --install teaches the agent to publish and report the link.

A folder with a README.md opens as a page. This is what a visitor sees at the link.

What you get

The CLI is open source and runs on your machine and your own Cloudflare account.

Stable links
https://<your-host>/<id>/<name>. The random id keeps links unguessable.
Snapshots
handout add <file|dir> copies it, so the link survives deleting the source. handout refresh updates under the same link.
Live dev servers
handout add 3000 proxies 127.0.0.1:3000 while it runs.
Folder page
Folders without index.html get a generated page: videos inline, images in a click-to-enlarge grid, other files with type and size.
Markdown rendering
With pandoc, .md renders in a paper reading theme, light and dark, with KaTeX math.
Expiry
30 days by default. --ttl 12h|7d|never.
Visitor counts
handout hits <id> shows requests and unique IPs.
Private links
--access email:a@x,b@y, domain:example.com or group:<rule group> puts a Cloudflare Access login on one link. The others stay public.
Safe copy
Dotfiles (.env, .git) and symlinks are never copied.
No domain needed
handout setup --quick serves at a random trycloudflare.com URL.
Always on
A login service (launchd or systemd) brings links back after a reboot.
Links with the machine off
With the R2 backend, snapshots sit in a private bucket and a Worker serves them while your laptop sleeps.
Members
One hostname for a team. handout member add ana --machine prints one line the teammate pastes once.
Profiles
handout --profile work ... runs a second setup beside the first.

How it works on your own Cloudflare account

There is no Handout server and no account to create with us. handout add copies into ~/share/pub, a local server serves it on localhost, and an outbound Cloudflare Tunnel publishes it at your hostname.

visitor

Opens your link

https://s.example.com/62cb50/guide/

your Cloudflare account

Edge, TLS and DNS

The hostname is yours. An outbound Tunnel carries the request in.

your machine

cloudflared and caddy

A login service keeps them up. Caddy serves 127.0.0.1:8787, no-store and noindex.

your machine

The files

~/share/pub/62cb50/guide/, only what you added.

  • Nothing leaves your machine until you say so. Nothing outside ~/share/pub is reachable.
  • No inbound port opens. The tunnel token lives in the Keychain, or in a mode-600 file on Linux.
  • No Handout account, no telemetry. The CLI talks to Cloudflare and to your machine.

Detail: how it works. The folder keeps the name ~/share from the first releases, so installs from before the rename keep working.

Install

Mac app, CLI for macOS and Linux, an install script, and an agent skill. Windows is not supported yet.

macOS

Mac app

Handout Bar lives in the menu bar: see what is shared, copy a link, drop a file on the icon to publish it. It also pulls the CLI.

# once: Homebrew refuses an untrusted tap
brew trust consolelabs/tap
brew install --cask consolelabs/tap/handout-bar
macOS and Linux

CLI

Pulls caddy, cloudflared and jq. Optional: brew install pandoc gh.

# once
brew trust consolelabs/tap
brew install consolelabs/tap/handout
handout setup s.example.com
No Homebrew

Install script

Or clone the repo and run ./install.sh: it symlinks bin/handout, so git pull updates it.

curl -fsSL https://raw.githubusercontent.com/consolelabs/handout/main/install.sh | bash
Claude Code and friends

Agent skill

Drops a SKILL.md so a coding agent can publish with Handout and report the link back.

handout skill --install

Then handout add ./team-guide prints the link and copies it. Coming from share? Run brew update: it moves you to consolelabs/tap/handout, and share stays a working alias.

FAQ and limits

What Handout does not do, said plainly.

What happens when my laptop sleeps?

On the default tunnel backend, links are live only while the machine is awake. Visitors get a Cloudflare 530 when it sleeps. For links that stay up, use the R2 backend: snapshots live in a private bucket and a Worker serves them.

Do I need a Cloudflare account and a domain?

You need a Cloudflare account, because Handout runs on yours. A domain on Cloudflare gives you the stable hostname. Without one, handout setup --quick serves at a random trycloudflare.com URL.

Is there a size limit?

On the R2 backend, one add holds at most 500 files, each at most 300 MiB.

Can I keep a link private?

Yes, per link, with a Cloudflare Access login by email, domain or group. It needs a named setup (not --quick) on a Cloudflare account with Zero Trust enabled, and a Cloudflare API token with Access permissions.

Can a team share one hostname?

Yes. Members publish from their own machines under your hostname. Members need the admin token, a separate minter token, and a Worker that has Workers VPC, which is a Cloudflare beta product, so members are off until you turn them on. Members are named teammates only.

Which platforms does it run on?

The CLI runs on macOS and Linux. The menu bar app is macOS only. Windows is not supported yet.

Does Handout see my files or track me?

No. There is no Handout server, no account with us and no telemetry in the CLI. Dotfiles and symlinks are never copied. A share from a private GitHub repo prints a warning, because the content is public to anyone with the link.

What does it cost, and what is the licence?

The CLI is open source (MIT) and self-hosted. Paid layers are planned and nothing is priced yet. The product direction page lists what could be paid and what is still undecided: DIRECTION.md.
